# AFK 낚시 모드

BMC5 서버용 클라이언트 전용 NeoForge 모드입니다. 창이 포커스를 잃어도 낚시를 계속합니다.
아이템, 블록, 네트워크 채널을 등록하지 않아서 서버에 이 모드가 없어도 접속할 수 있습니다.

- Minecraft 1.21.1, NeoForge 21.1.250 이상, Java 21

## 조작

- `F8`: 시작/정지
- `J`: 설정 화면 (모드 목록의 Config 버튼으로도 열림)

## 동작

- 마우스 입력 대신 `gameMode.useItem()`을 직접 호출해서 던지고 회수합니다. 그래서 창 포커스와 상관없이 동작합니다.
- 입질은 서버가 동기화해 주는 `FishingHook.biting` 값으로 감지합니다(access transformer). 회수는 사람처럼 무작위로 조금 늦게 합니다.
- **AFK 킥 방지**: 기본 5분 ± 30초마다 재투척 대기 중에 한 걸음 갔다가 제자리로 돌아옵니다.
  - 움직이기 전에 갈 칸이 막혔는지, 발밑에 땅이 있는지, 물이나 용암인지 검사합니다.
  - 돌아올 때는 시작 위치와의 오차를 보정합니다.
- **탁 트인 물 판정**: 바닐라 보물 조건을 그대로 검사해서 HUD에 표시합니다. 깨졌으면 어느 칸의 어떤 블록 때문인지 보여 줍니다.
- **Hybrid Aquatic 낚싯바늘**: 바늘은 낚을 때마다 내구도가 1씩 닳습니다(자석 8, 가시·발광 16).
  - 부서지면 인벤토리의 예비 바늘을 왼손에 다시 채웁니다.
  - 예비가 없으면 정지합니다.
- **찌 회수**: 정지하거나 접속을 끊기 전에 찌를 먼저 회수합니다. 찌가 나간 채로 접속이 끊기면 서버가 바늘을 돌려주지 않고 찌를 지우기 때문입니다.
- **안전 정지**: 피격, 사망, 인벤토리 가득 참(설정으로 끌 수 있음), 쓸 수 있는 낚싯대 없음, 찌가 물에 계속 안 들어갈 때 정지합니다.
- **HUD**: 상태, 잡은 수, 탁 트인 물 여부, 낚싯대와 바늘 내구도, 마지막 회수 이유, 다음 이동까지 남은 시간을 표시합니다.

## 빌드

```powershell
.\gradlew.bat build
```

NeoForm 재컴파일 단계는 JRE가 아니라 **JDK 21**이 필요합니다. 마인크래프트에 들어 있는 런타임은 JRE라서 쓸 수 없습니다.
`JAVA_HOME`을 JDK 21로 지정하거나, 사용자 폴더의 `~/.gradle/gradle.properties`에 `org.gradle.java.home`을 넣으세요.

결과물은 `build/libs/afkfishing-<버전>.jar`이고, 인스턴스의 `mods` 폴더에 넣으면 됩니다.
