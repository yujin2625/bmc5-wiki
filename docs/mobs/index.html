BMC5 몹 사육 도감

Better MC 5에 들어 있는 몹을 길들이고 번식시키는 방법을 모았습니다. 카드를 누르면 자세한 방법이 나오고, 별표와 리스트로 자주 보는 몹을 모아 둘 수 있습니다.

필터
방법
모드

데이터 출처 이 모드팩에 설치된 Just Enough Breeding 모드의 레시피 데이터와 각 모드의 아이템 태그를 직접 읽어서 만들었습니다. 길들이기 확률, 조건, 특수한 방법은 바닐라와 각 모드의 실제 코드와 이 서버의 설정 파일을 읽어서 확인했습니다. 몹 그림은 게임 파일 속 각 몹의 3D 모델과 텍스처로 직접 그렸습니다.

체력·스폰·드롭 체력과 공격력은 각 몹의 속성 등록 코드, 사는 곳은 바이옴 데이터와 모드 스폰 설정, 떨어뜨리는 것은 전리품 테이블에서 뽑았습니다. 이 PC의 설정 기준이라 서버 설정과 다를 수 있습니다. 체력 하트 1칸은 2입니다.

즐겨찾기와 리스트 별표와 리스트는 지금 쓰는 브라우저에만 저장됩니다. 다른 기기나 브라우저에서는 따로 만들어야 합니다.

게임 안에서 확인 EMI에서 몹의 먹이 아이템을 찾아 사용처(U)를 보면 번식과 길들이기 탭이 나옵니다. 서버에 데이터팩이 따로 있으면 먹이가 이 문서와 다를 수 있습니다.
